# fluML
Transformer-based framework for modeling and forecasting influenza A/H3N2 HA evolution using sequence, temporal, geographic, and epitope-aware features

This repository contains a Transformer-based framework for modeling and forecasting the evolution of Influenza A/H3N2 hemagglutinin (HA) sequences.

The model combines protein sequence information with biologically and epidemiologically relevant features, including:

Amino-acid sequence embeddings
Temporal information derived from collection dates
Geographic transmission-zone embeddings
Position-specific amino-acid frequencies
Temporal frequency trends
Epitope-site annotations
Entropy-based variability measures
Reference consensus sequences

The framework is designed to investigate viral evolutionary dynamics and identify positions associated with emerging antigenic change.
